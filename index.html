🤖 AI 마인드맵 업로드

아래 프롬프트를 복사해 Claude, ChatGPT 등 AI에게 전달하세요:

AI가 JSON을 생성하면 "JSON 가져오기" 탭에서 붙여넣기 하세요.

{ "name": "카테고리 이름", "nodes": { "root": { "title": "중심 주제", "source": "참고 자료", "items": ["핵심 내용 1", "핵심 내용 2"], "quote": "핵심 인용구", "color": "#1e293b" }, "branch1": { "title": "1단계 가지", "parent": "root", "source": "출처", "items": ["내용1", "내용2"], "color": "#4f46e5" }, "cluster1-1": { "title": "2단계 클러스터", "parent": "branch1", "items": ["내용"], "color": "#9333ea" }, "leaf1-1-1": { "title": "세부 내용", "parent": "cluster1-1", "items": ["상세 설명"] } } }
필드 설명
• name: 카테고리 이름 (필수)
• root: 반드시 포함, parent 없음 (필수)
• parent: 부모 노드 key, 루트 제외 필수
• title: 노드 이름 (필수, 줄바꿈: \n)
• items: 내용 목록 배열 (선택)
• quote: 인용구 문자열 (선택)
• color: hex 색상, 1~2단계 노드 권장
